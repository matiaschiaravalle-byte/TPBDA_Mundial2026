# TPBDA_Mundial2026

Sistema de registro y gestión del mundial de fútbol creado por los integrantes del grupo 10.

- Matías Ezequiel Chiaravalle
- Nahuel Battistelli
- Agustín Nicolás Mussi Pulcini

El sistema se encarga de gestionar la información de jugadores, sedes, partidos, altas y bajas entre otras cosas, permitiendo la importación masiva de datos y creación de diferentes roles de seguridad, enfocado a distintos tipos de usuario dentro de la organización.
